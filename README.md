Hangman Game

​A simple, text-based Hangman game built using Python.

​Description

​This program selects a random word from a predefined list. The player attempts to guess the word letter by letter, with a limited number of allowed incorrect attempts.

​Features

​Random Word Selection: Picks a random word for every new game session.

​Word Display: Represents unguessed letters with blank underscores (_).

​Interactive Gameplay: Displays remaining attempts and tracks already guessed letter
